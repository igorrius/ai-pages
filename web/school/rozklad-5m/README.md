# Розклад 5-М — PWA

Інтерактивний розклад уроків 5-М класу (Київський ліцей №29 ім. П. Калнишевського).

Файли: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-*.png`. Усі шляхи відносні,
тому папку можна переносити куди завгодно. Залежностей і збірки немає — один HTML-файл.

## Адреса
https://igorrius.github.io/ai-pages/web/school/rozklad-5m/

## Що вміє
- **Зараз / Далі** — поточний урок із смужкою прогресу, зворотний відлік до дзвінка,
  наступний урок. До початку занять, на перерві, після уроків і у вихідні — свої стани.
- **Один день на телефоні, весь тиждень на планшеті/десктопі** (межа — 900 px).
  Перемикання днів: таби, свайп, стрілки ←/→, `Home` — повернутись на сьогодні.
- **Темна тема** — автоматично за налаштуванням системи.
- **Фільтр за предметом**, деталі уроку в модальному вікні, друк тижня (Ctrl+P).
- **Офлайн** — після першого відкриття працює без мережі.

## Встановлення на телефон
- Android/Chrome — кнопка «Встановити на телефон» (або меню ⋮ → «Додати на головний екран»).
- iPhone/Safari — Поділитися → «На Початковий екран».

GitHub Pages віддає сайт по HTTPS, що обов'язково для роботи PWA.

## Оновлення розкладу
1. Правиш `DAYS` / `BELLS` в `index.html`.
2. У `sw.js` піднімаєш `VERSION` (наприклад `v5` → `v6`).
3. Пушиш.

Уже відкриті застосунки покажуть плашку «Доступна нова версія розкладу» з кнопкою
«Оновити» — сторінка перезавантажиться лише після натискання, не посеред перегляду.

### Формат даних
```js
// L(предмет, вчитель або [вчителі], кабінет)
1:[L("math","Рябошапка В.С.","213")],              // один урок
3:[L("live","Парахонько М.М."), L("health","…")],  // дві групи паралельно
```
Ключі предметів і кольори — у константі `SUBJ`. Кабінет можна не вказувати:
у розкладі він відобразиться як «—».
