# Розклад 5-М — PWA

Інтерактивний розклад уроків 5-М класу (Київський ліцей №29 ім. П. Калнишевського).

Файли: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-*.png`. Усі шляхи відносні,
тому папку можна переносити куди завгодно. Залежностей і збірки немає — один HTML-файл.

## Адреса
https://igorrius.github.io/ai-pages/web/school/rozklad-5m/

## Що вміє
- **Зараз / Далі** — поточний урок із смужкою прогресу, зворотний відлік до дзвінка,
  наступний урок. До початку занять, на перерві, після уроків і у вихідні — свої стани.
- **Один день на телефоні, весь тиждень на планшеті/десктопі** (межа — 900 px).
  Перемикання днів: таби, свайп, стрілки ←/→, `Home` — повернутись на сьогодні.
- **Темна тема** — автоматично за налаштуванням системи.
- **Фільтр за предметом**, деталі уроку в модальному вікні, друк тижня (Ctrl+P).
- **Офлайн** — після першого відкриття працює без мережі.

## Встановлення на телефон
- Android/Chrome — кнопка «Встановити на телефон» (або меню ⋮ → «Додати на головний екран»).
- iPhone/Safari — Поділитися → «На Початковий екран».

GitHub Pages віддає сайт по HTTPS, що обов'язково для роботи PWA.

## Telegram Mini App
Та сама сторінка відкривається як міні-застосунок у Telegram. Окремого хостингу чи збірки
не потрібно: Telegram просто показує цю адресу у вбудованому вікні.

Що змінюється всередині Telegram:
- тема (світла/темна) і колір шапки беруться з налаштувань Telegram;
- вікно одразу розгортається на весь екран;
- кнопка «Назад» Telegram закриває деталі уроку;
- при перемиканні дня відчувається легка вібрація;
- посилання на підручники відкриваються через Telegram;
- кнопки «Встановити на телефон» немає.

SDK `telegram-web-app.js` вантажиться лише тоді, коли сторінку відкрив Telegram. У звичайному
браузері й офлайн сторінка працює як і раніше.

### Як підключити (один раз, через @BotFather)
1. `/newbot` — створити бота (наприклад, `rozklad5m_bot`).
2. `/newapp` → вибрати бота → назва, опис, картинка 640×360 →
   URL `https://igorrius.github.io/ai-pages/web/school/rozklad-5m/` → коротка назва (наприклад, `rozklad`).
   Посилання для класу: `https://t.me/rozklad5m_bot/rozklad`.
3. (За бажанням) `/mybots` → бот → *Bot Settings* → *Menu Button* → той самий URL.
   Тоді в чаті з ботом з'явиться кнопка «Розклад» біля поля введення.

## Оновлення розкладу
1. Правиш `DAYS` / `BELLS` в `index.html`.
2. У `sw.js` піднімаєш `VERSION` (наприклад `v6` → `v7`).
3. Пушиш.

Уже відкриті застосунки покажуть плашку «Доступна нова версія розкладу» з кнопкою
«Оновити» — сторінка перезавантажиться лише після натискання, не посеред перегляду.

### Формат даних
```js
// L(предмет, вчитель або [вчителі], кабінет або [кабінети])
1:[L("math","Рябошапка В.С.","319")],                       // один урок
3:[L("live","Парахонько М.М.","124"),                       // дві групи паралельно —
   L("health","Романенко І.В.","124")],                     // окремі картки в одному слоті
5:[L("inf",["Бернатович О.О.","Яковенко В.А."],             // одна картка, дві групи:
       ["311","107"])],                                     // кожен вчитель у своєму кабінеті
```
Ключі предметів і кольори — у константі `SUBJ`. Кабінет можна не вказувати:
у розкладі він відобразиться як «—». Якщо передати масив кабінетів, він має
збігатися за довжиною зі списком вчителів; на картці кабінети покажуться і
в значку (`311/107`), і біля кожного вчителя.

### Дистанційний день
Якщо день повністю онлайн, додай йому `online:true` і не вказуй кабінети:

```js
{short:"Пт", name:"П'ятниця", online:true, lessons:{ /* ... */ }},
```

Тоді замість кабінету картки показують значок «💻 онлайн», у табі дня
з'являється 💻, у шапці колонки — «· онлайн», у блоці «Зараз / Далі» —
«онлайн» замість «каб. …», а в деталях уроку — рядок «Формат: онлайн,
дистанційно». У сітці тижня (від 900 px) значок на картках приховано —
там про онлайн каже шапка дня.
